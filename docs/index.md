## Architecture Overview

```
User / Frontend
      │
      ▼
FastAPI (backend/app/main.py)
      │
      ├── POST /api/v1/generation/generate  →  GenerationJob created → QUEUED
      │
      └── Background Worker (backend/worker.py)
                │
                ├── MOCK provider    → in-process placeholder images
                │
                └── KAGGLE_BATCH    → manifest push → Kaggle GPU → download → validate
                                                                                │
                                                              NasalDeformationEngine
                                                                                │
                                                                        ZIP export
```
